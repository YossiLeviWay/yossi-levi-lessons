# המצגות של יוסי לוי

אתר סטטי של מצגות ההשתלמויות של יוסי לוי. GitHub Pages מגיש את האתר מענף `main`, משורש המאגר.

## הוספת שיעור חדש

1. מוסיפים תיקייה תחת `lessons/<id>/` עם `index.html` ותיקיית `assets` של השיעור.
2. מוסיפים רשומה למערך `window.LESSONS` בקובץ `catalog.js` עם השדות: `id`, `title`, `description`, `details`, `cover`, `url`, ו־`worksheet` (רשות).
